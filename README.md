# 🚀 Fraud Detection API (AWS Deployment)

## 🔹 Project Overview
This project is a real-time Fraud Detection API built using Machine Learning and deployed on AWS EC2. It detects fraudulent transactions using an anomaly detection model.

---

## 🧠 Tech Stack
- Python
- Flask (API)
- Scikit-learn (Isolation Forest)
- AWS EC2 (Cloud Deployment)
- Gunicorn (WSGI Server)
- Nginx (Reverse Proxy)

---

## ⚙️ Features
✔ Real-time fraud prediction  
✔ REST API endpoint  
✔ Scalable cloud deployment  
✔ Production-ready architecture  
✔ Lightweight ML model
